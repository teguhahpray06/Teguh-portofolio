# TeguhAPPortofolio

Portfolio pribadi Teguh Ahmad Prayogo yang menampilkan pengalaman, project, skills, dan tech stack dalam pengembangan solusi digital.

## Menjalankan Project

```bash
npm install
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000) di browser.

## Deployment

Project ini siap di-deploy ke Vercel menggunakan framework Next.js.
